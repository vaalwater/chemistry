## 2. App 预览位（只接受视频，不接受图片）

- 格式 `.mp4` / `.mov`，15–30s，H.264。
- 尺寸：**1920 × 886（横）** 或 **886 × 1920（竖）**。
- ⚠️ 实测：传静态 PNG 即使像素尺寸精确（886×1920 / 1920×886）也报「文件尺寸无效」，
  **别再拿图片试**。
- 录制：Playwright 录 web 操作（viewport `443×960 @2x`，`recordVideo.size = {886,1920}`）
  得 webm，再
  `ffmpeg -i in.webm -c:v libx264 -pix_fmt yuv420p -r 30 -an -movflags +faststart out.mp4`
  （ffmpeg 已用 brew 装好）。

## 3. 建议截图的关键页面（每套槽位 6–10 张）

优先展示「可旋转的 3D」这一核心卖点，并覆盖三科：

1. 首页（化学 / 数学 / 物理 三张学科卡片）
2. 化学浏览页（分子 / 反应 / 动手 三个 tab）
3. 分子 3D 页（如 `H₂O` 或 `NaCl` 球棍模型，已旋转到一个好角度）
4. 原子构造器 / 原子 3D 页（电子层排布）
5. 化学反应页（配平演出，带物质名称标签）
6. 酸碱实验页（H⁺ / OH⁻ 对比条）
7. 立体几何页（多面体）
8. 电磁学页（电场线 / 磁感线）
9. 知识点汇总页（长文 + 行内链接）
10. 问答助手悬浮小猫弹窗（optional，展示体验）

> 截图前确保 3D 画布角度是「展示性」的（而不是默认正面），底部介绍卡片不要过长
> 以至压扁画布（见 `CLAUDE.md` §10）。

## 5. 生成脚本（make-screenshots.cjs）——已就位

脚本在本目录：`appstore/screenshots/make-screenshots.cjs`（Playwright + web 版渲染）。
原脚本此前放在 `ios/build/`（DerivedData 临时目录）已丢失，本脚本是按同一规格重建的。

运行步骤：

```bash
# 1) 启动 web dev server（后台或另开终端）
npx expo start --web --port 8099

# 2) 生成截图（可带尺寸参数：6.1-6.3 / 6.9 / duo / 不带=全部）
node appstore/screenshots/make-screenshots.cjs 6.1-6.3
node appstore/screenshots/make-screenshots.cjs 6.9
```

- 依赖：`npm i -D playwright` + `npx playwright install chromium`（本机已装好）。
- 3D 页用 swiftshader 软渲染 WebGL（`--use-gl=angle --use-angle=swiftshader`），
  实测水分子球棍模型渲染正常。
- 导航用**可见文本**点击：首页卡片「化学 / 数学 / 物理」（注意「进入XX频道」只是
  accessibilityLabel，不可见）、tab「反应 / 动手」、分子卡片「水」等。
- 原子 3D 页已从脚本移除：窄屏下周期表格子（cellW < 22）不显示任何文字，无法用
  文本定位；分子 3D 已足以展示 3D 能力。
- ⚠️ 模拟器 Debug 构建目前不可用（Expo SDK 57 + Xcode 27/Swift 6.4），截图走 web 路线。
