**App name:** 理科3D视界 (STEM 3D World)
**Bundle ID:** com.rongweiwei.chem3dclassroom
**Version:** 2.0.1 (build 4)
**Category:** Education

---

### 1. App purpose (what the app does)

This is an **offline educational app** for middle- and high-school science (Chemistry,
Mathematics, Physics). It renders abstract STEM concepts as **interactive 3D models**
that users can rotate and zoom with touch:

- Chemistry: 3D molecular / atomic structures, chemical-reaction playback, acid–base
  and ionic-radius labs, an atom-builder for isotopes.
- Mathematics: solid geometry, sets, extrema, and a drawing playground.
- Physics: electromagnetism — electric/magnetic field lines, Ampere and Lorentz forces.
- A textbook-style knowledge summary with deep links into the 3D scenes.

There is **no account, no login, and no server-side backend**. All 3D engines are
bundled inside the app.

### 2. Data collection & privacy

The app **does not collect any personal information**. Specifically:

- No account creation, no login, no profile.
- No analytics, no advertising, or third-party tracking SDKs.
- The only local storage written is the user's own **drawing草稿** in the math
  "drawing" module (saved locally on device; on the web build it uses `localStorage`,
  on iOS it stays in memory).
- The app itself makes **no network requests** unrelated to teaching. The 3D engines
  are packaged inside the bundle and run fully offline.

Privacy policy (must match in-app text): https://<你的站点>/privacy.html

### 3. Login / account requirement

**None.** The app is fully usable without any account. The "Ask assistant" feature
(optional, see item 5) opens a third-party web page in a WebView; if that site asks
for login, it is handled entirely by the third party and is **not required** to use
the core app.

### 4. Advertising

**No advertisements** of any kind — no banner, interstitial, or rewarded ads, and no
ad SDK is included in the dependencies.

### 5. Third-party content (the "Ask assistant" feature)

The app includes an **optional** floating assistant that opens a third-party search /
chat website (e.g. Bing, DeepSeek) inside a WebView so students can look things up.
This is clearly presented as a third-party page, the user can close or disable it at
any time (toggle in the About screen), and:

- The app **does not collect, store, or transmit** anything the user types there.
- Login to the third-party site, if any, is performed by that site itself.
- The WebView uses a mobile user-agent and a prominent, always-visible close button.

### 6. In-App Purchase / Permissions

- **No In-App Purchases**, no subscriptions.
- The app requests **no system permissions** for its core function.
- The only permission strings declared are for the **photo library** (used only if the
  user chooses to pick/save a learning-related image) and **microphone/speech**
  (only used when the user explicitly presses the voice-input button in the assistant).
  Both are optional and explained in the permission prompts.
